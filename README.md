# Rahul Meena Portfolio

Minimal single-page portfolio inspired by the layout rhythm of the provided reference, with original styling and Rahul's own content.

## Deploy to Vercel
1. Create a new GitHub repository.
2. Upload `index.html`, `styles.css`, `script.js`, `Rahul_Meena_Resume.pdf`, and `vercel.json`.
3. Import the repository in Vercel.
4. Framework preset: `Other`.
5. Deploy.

No build step is required.
